# Registro de Decisões

Decisões que afetem mais de uma feature devem ser registradas neste diretório.

Formato:

```text
NNNN-titulo-curto.md
```

Cada decisão deve conter:

- contexto;
- alternativas consideradas;
- decisão;
- impactos e riscos;
- data e status;
- features afetadas.

Decisões previstas:

- geração parcial de tipos OpenAPI;
- seleção explícita de academia e função;
- estratégia para contratos de resposta genéricos.
